For TAMA team members

Updating the website

No code needed. New events are submitted through a form and approved before going live. News and clinic updates are made in a shared Google Sheet, and the site picks them up automatically.

Events with tickets

Adding a new event

Events with ticket sales are added in two steps. First a team member submits the event. Then the president approves it. Approving puts the event on the website and turns on ticket sales at the same time.

1. Submit

Fill in the event name, date, time, venue, description, and member and public ticket prices. Works on a phone.

Submit an event

2. Approve

The president reviews each submission. Approving makes the event live with ticket sales. Rejecting hides it.

How it works

Edit the sheet, the site updates itself

The homepage reads its news and clinic sections from a Google Sheet. When you edit the sheet, the changes appear on the website within a few minutes. You never touch the website code. You only need a Google account. (Events are handled through the submission form above, not the sheet.)

If the sheet is ever unavailable or has a problem, the website simply keeps showing its built-in content. The site never looks broken.

One-time setup

Setting up the sheet

1. Create the sheet

Create a new Google Sheet. Make two tabs named exactly News and Clinic.

2. Add the template

Download the template CSV. For each tab, copy the header row and the example row under that tab's label into the matching tab, then delete the label rows.

3. Publish it

In the sheet, go to File > Share > Publish to web. Publish the entire document. This is what lets the website read it.

4. Send the sheet ID

Copy the long ID from the sheet's URL (the part between /d/ and /edit). Send it to the site maintainer. They paste it into one line of the site config, and the live updates switch on.

5. Share with the team

Share the sheet with every team member who may edit it. Editors need a Google account. Viewers of the website need nothing.

Column guide

What goes in each column

News tab

  • text: the news item, one short line.
  • date: optional short label, like "Oct 2026". Leave blank if not needed.

Clinic tab

  • title: the clinic heading, usually "Free Medical Clinic".
  • schedule: plain text clinic days and hours.
  • description: one or two short sentences about the clinic.
  • register_url: the full clinic registration link, starting with https://. Leave blank if there is none yet.

Only the first row of the Clinic tab is used.

Rules

Please do not

  • Never rename the tabs or the columns.
  • Never reorder or delete columns.
  • Type dates and times as plain text, not as Sheet date formats.
  • Keep banner images under 300 KB so the site stays fast on phones.
The membership signup still uses the existing tama.org registration system. That part is unchanged and is not edited through the sheet.
